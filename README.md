# T4cceptor Homebrew Tap

This is the official Homebrew tap for [MakeMCP](https://github.com/T4cceptor/MakeMCP).

## Installation

```bash
brew tap T4cceptor/makemcp
brew install makemcp
```

## Available Formulae

- **makemcp** - Transform APIs into MCP servers for AI agents

## About MakeMCP

MakeMCP is a Go CLI tool that creates MCP (Model Context Protocol) servers from various sources, enabling AI agents to interact with diverse systems through a unified interface.
